# Code of Conduct

## Our Standard

Participants in this project are expected to be respectful, direct, and constructive.

Examples of expected behavior:

- Give technical feedback about the work, not the person.
- Assume good intent unless there is clear evidence otherwise.
- Use inclusive, professional language.
- Accept correction without escalating conflict.

Examples of unacceptable behavior:

- Harassment, insults, or discriminatory language.
- Repeated bad-faith arguments or personal attacks.
- Publishing private information without permission.
- Deliberate disruption of discussions, reviews, or issue triage.

## Scope

This applies to issues, pull requests, discussions, code review, and any other project communication channels.

## Enforcement

Project maintainers may remove content, restrict participation, or ban contributors whose behavior violates this policy.

## Reporting

For conduct concerns, contact the project maintainers privately rather than escalating in public threads.
